# Content sources and verification log

drychem.com was **not directly reachable** from the build environment (the
host is outside its network allowlist), so the site's content was assembled
from DRYCHEM's own pages **as indexed by web search** on 29 October 2026. No
figure, certification or product name was invented. Every claim below links to
the official page it came from. Re-check them against the live site before
launch.

The copy itself (headlines, statements, transitions between facts) is new,
written for an international B2B audience, but it only restates the facts
listed here.

## Items to confirm before launch

These came up inconsistent or only partly verifiable. The site takes the most
conservative reading, but they need a human check:

1. **Non Shrinkage Grout grades.** The product menu lists NSG 50 / 65 / 73;
   one blog post says NSG 50 / 65 / 75. The site uses the menu (73).
2. **Coatings range.** Crack Filler, Gypsum Based Crack Filler and Powder
   Primer are confirmed. Search summaries also mentioned a Cement Primer and a
   Powder Paint, but they couldn't be confirmed, so they are **not** listed.
3. **Crack Filler use.** One page says "for indoor use only" and also "internal
   and external walls". The site doesn't state where it can be used.
4. **MasterMix pack size.** Wall Putty MasterMix is 25 kg per 1 MT batch on two
   pages; one Ready Mix Plaster page mentions 5 kg. The site uses the 25 kg
   figure, which is better supported.
5. **Head office wording.** The About page says "headquartered in Mumbai"; the
   contact page gives the Navi Mumbai (Mahape) registered office. The site uses
   the contact-page address.
6. **Leveling Solutions contents.** Taken from the menu (plastering and gypsum
   solutions). Confirm the grouping matches the live catalogue.
7. **Social media.** No official profiles could be verified, so none are
   linked. Add them in `src/components/layout/SiteFooter.tsx` if wanted.

## Deliberately not used

- Third-party claims (employee counts, "great place to work" listings,
  registry data) — not DRYCHEM's own statements.
- Technical performance values (strengths, coverage, drying times). These
  belong in official data sheets; the site points visitors to request the
  latest TDS instead.

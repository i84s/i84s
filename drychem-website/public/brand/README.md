# Logo files

Generated by `scripts/trace_logo.py` from the IMC logo artwork the client
supplied (`brand-source/`). Don't edit them by hand; re-run the script instead.

| File                           | Artwork                                            | Used in                                |
| ------------------------------ | -------------------------------------------------- | -------------------------------------- |
| `imc-mark.svg`                 | The IMC symbol                                     | Header over light sections             |
| `imc-mark-reversed.svg`        | The IMC symbol for dark surfaces                   | Header, opening sequence, page curtain |
| `imc-horizontal-reversed.svg`  | Symbol with the company name in Arabic and English | Footer                                 |
| `imc-horizontal.svg`           | Same, full colour                                  | Not used yet (light surfaces)          |
| `imc-stacked.svg`, `-reversed` | Stacked lockup ("INDUSTRIAL MINERALS COMPANY")     | Not used yet (square placements)       |
| `favicon.svg`                  | The symbol on a white rounded tile                 | Browser tab icon                       |

The reversed versions swap the logo's green for off-white (`#f2f0eb`) and keep
the teal. That treatment was derived for this site, not supplied: confirm it
with the brand owner. If official vector files exist, export them under the
same names and update the sizes in `src/generated/logos.json`. See
`docs/BRAND-SLOTS.md`.
